How to read this table

  • One row per human input and mouse ortholog pair. Inputs that resolve to the same human gene (e.g. a synonym or an Ensembl ID) are kept as separate rows and flagged.
  • Jaccard = shared terms / all terms across human and mouse (0 = no overlap, 1 = identical). Brackets give shared/union counts. MF = molecular function, BP = biological process, CC = cellular component; UniProt = UniProt subcellular-location terms.
  • Call agreement = tissues where Bgee gives the same present/absent call in both species, over tissues with an eligible call in both. Present-tissue J = tissues present in both / tissues present in either.
  • Local API vs NCBI compares Gene ID, symbol, name, chromosome, locus and aliases from the course web service with the NCBI record.
  • N/A always states why a value is missing (unresolved input, no ortholog, non-coding gene, missing annotation). It never means zero.

Sources: NCBI Gene and Datasets orthologs, UniProtKB, Bgee, local course API (bioinfmsc6). Gene symbols and accessions link to the source records.

SQL query that built this table 
SELECT a.Input_Row, a.Query_Symbol, a.Resolution_Status, a.Resolution_Note,
       a.Gene_ID, a.Official_Symbol, a.Official_Name, a.Chromosome, a.Map_Location,
       a.ENSG_IDs, h.Gene_Type AS Human_Gene_Type,
       (SELECT MIN(d.Input_Row) FROM p1_annotations d
         WHERE d.Dataset = a.Dataset AND d.Gene_ID = a.Gene_ID) AS First_Input,
       o.Mouse_Gene_ID, o.Mouse_Symbol, o.Mouse_Official_Name,
       o.Mouse_Ensembl_Gene_ID, o.Mouse_Ortholog_Count, o.Mapping_Status, o.Mapping_Note,
       hp.Accessions AS Human_UniProt, hp.N_Reviewed AS Human_Reviewed,
       mp.Accessions AS Mouse_UniProt, mp.N_Reviewed AS Mouse_Reviewed,
       s.GO_MF_Jaccard, s.GO_BP_Jaccard, s.GO_CC_Jaccard, s.Location_Jaccard,
       JSON_LENGTH(s.GO_MF_Shared_IDs) AS GO_MF_Shared,
       s.GO_MF_Human_Count + s.GO_MF_Mouse_Count - JSON_LENGTH(s.GO_MF_Shared_IDs) AS GO_MF_Union,
       JSON_LENGTH(s.GO_BP_Shared_IDs) AS GO_BP_Shared,
       s.GO_BP_Human_Count + s.GO_BP_Mouse_Count - JSON_LENGTH(s.GO_BP_Shared_IDs) AS GO_BP_Union,
       JSON_LENGTH(s.GO_CC_Shared_IDs) AS GO_CC_Shared,
       s.GO_CC_Human_Count + s.GO_CC_Mouse_Count - JSON_LENGTH(s.GO_CC_Shared_IDs) AS GO_CC_Union,
       JSON_LENGTH(s.Location_Shared_IDs) AS Location_Shared,
       s.Location_Human_Count + s.Location_Mouse_Count
         - JSON_LENGTH(s.Location_Shared_IDs) AS Location_Union,
       s.Comparable_Tissue_Count, s.Concordant_Tissue_Count,
       s.Expression_Call_Agreement, s.Present_Tissue_Jaccard,
       t.Differing_Tissues, t.N_Differing,
       l.Comparison_Status AS Local_Comparison, l.Local_Status, l.Differences AS Local_Differences,
       l.Missing_Fields AS Local_Missing,
       CASE WHEN a.Resolution_Status <> 'resolved' THEN 'input not resolved to a human gene'
            WHEN o.Mouse_Gene_ID IS NULL THEN 'no mouse ortholog returned by NCBI'
            WHEN 'not_applicable_gene_type' IN (h.UniProt_Status, m.UniProt_Status)
                 THEN 'non-coding gene: no protein expected'
            WHEN s.Protein_Comparison_Status <> 'annotation_overlap_only'
                 THEN REPLACE(s.Protein_Comparison_Status, '_', ' ')
       END AS Protein_Note,
       CASE WHEN a.Resolution_Status <> 'resolved' THEN 'input not resolved to a human gene'
            WHEN o.Mouse_Gene_ID IS NULL THEN 'no mouse ortholog returned by NCBI'
            WHEN s.Expression_Comparison_Status <> 'comparable'
                 THEN REPLACE(s.Expression_Comparison_Status, '_', ' ')
       END AS Expression_Note
FROM p1_annotations a
LEFT JOIN p2_orthologs o ON o.Dataset = a.Dataset AND o.Input_Row = a.Input_Row
LEFT JOIN p3_pair_summary s     ON s.Dataset = a.Dataset AND s.Input_Row = a.Input_Row
                      AND s.Mouse_Gene_ID <=> o.Mouse_Gene_ID
LEFT JOIN p3_gene_status h     ON h.Dataset = a.Dataset AND h.Species = 'human' AND h.Gene_ID = a.Gene_ID
LEFT JOIN p3_gene_status m     ON m.Dataset = a.Dataset AND m.Species = 'mouse' AND m.Gene_ID = o.Mouse_Gene_ID
LEFT JOIN (SELECT Dataset, Species, Gene_ID, SUM(Reviewed = 1) AS N_Reviewed,
                  GROUP_CONCAT(UniProt_Accession ORDER BY Reviewed DESC, UniProt_Accession) AS Accessions
             FROM p3_uniprot WHERE Selected = 1 GROUP BY Dataset, Species, Gene_ID) hp
       ON hp.Dataset = a.Dataset AND hp.Species = 'human' AND hp.Gene_ID = a.Gene_ID
LEFT JOIN (SELECT Dataset, Species, Gene_ID, SUM(Reviewed = 1) AS N_Reviewed,
                  GROUP_CONCAT(UniProt_Accession ORDER BY Reviewed DESC, UniProt_Accession) AS Accessions
             FROM p3_uniprot WHERE Selected = 1 GROUP BY Dataset, Species, Gene_ID) mp
       ON mp.Dataset = a.Dataset AND mp.Species = 'mouse' AND mp.Gene_ID = o.Mouse_Gene_ID
LEFT JOIN (SELECT Dataset, Input_Row, Mouse_Gene_ID,
                  SUM(Comparison_Status = 'different_call') AS N_Differing,
                  GROUP_CONCAT(CASE WHEN Comparison_Status = 'different_call'
                               THEN CONCAT(COALESCE(Tissue_Name, Tissue_ID),
                                           ' (H ', Human_Call, ' / M ', Mouse_Call, ')') END
                               ORDER BY Tissue_Name SEPARATOR '; ') AS Differing_Tissues
             FROM p3_tissue_comparison GROUP BY Dataset, Input_Row, Mouse_Gene_ID) t
       ON t.Dataset = a.Dataset AND t.Input_Row = a.Input_Row AND t.Mouse_Gene_ID <=> o.Mouse_Gene_ID
LEFT JOIN p4_local_ncbi_comparisons l    ON l.Dataset = a.Dataset AND l.Input_Row = a.Input_Row
WHERE a.Dataset = %(dataset)s
ORDER BY a.Input_Row, o.Mouse_Gene_ID
